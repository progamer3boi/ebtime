# Changes

## 0.2.0 preview

- Replaced the Lua text-graph window with a separately hosted Qt editor.
- Added original @epicbloxfx branding and a restrained dark interface.
- Added draggable points and handles, exact Bezier curve splitting, point deletion, smooth/straight tangents and numerical point controls.
- Added 28 thumbnail presets, category/search filters, source-position and speed graphs, and an animated graph playhead.
- Added curve editing Undo/Redo, local saved/imported/exported presets, accent preferences, snap and guides.
- Added a fixed Apply footer and scrollable controls for smaller windows.
- Added Windows install/designer launchers and an isolated PySide6 runtime.
- Added a Resolve-side Python bridge: modal edit/apply/cancel, per-effect state, unique response files and generated Lua with composition unlock/Undo cleanup.
- Kept native Optical Flow/Time Stretcher rendering. Actual Resolve/Windows execution remains to be tested.
